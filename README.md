# ComplantPortal

1. Clone the project into System
2. Open Terminal at Top section and in between Run and Help of Vs code
3. Run this command npm install (or) npm install --force
4. Right click on data.json file
5. Select Open Integrated Terminal
6. Run this command json-server --watch data.json --port 3000
7. After that Open another Terminal at Top section and in between Run and Help of Vs code
8. Run this command ng s
